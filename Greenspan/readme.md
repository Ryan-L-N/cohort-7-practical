# AI Technician — Cohort 7 Practical Exercise

This repository is where you will submit your solutions for the multi-step practical exercise.

## Instructions

1. **Fork this repository** to your own GitHub account.
2. **Create a folder named with your last name** in the root of your forked repository (for example, Smith).
3. **Upload your solutions** into that folder, following the naming and organization described in the practical exercise instructions.
4. **Once complete**, open a pull request so your solutions can be pulled into the upstream by a Cohort Mentor.

## Example Structure

`
/Smith
   problem1-solution.py
   problem2-solution.py
   problem3-solution.py
`

## Notes

- Only add files inside your own last-name folder.
- If someone in the cohort shares your last name, add your first initial (for example, Smith-J).
- Refer to the practical exercise powerpoint for the instructions on how to get started.
